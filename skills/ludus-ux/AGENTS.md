# Ludus UX agents

When working in this repository or operating a Ludus lab through Ludus UX:

1. Read `skills/ludus-ux/SKILL.md` and `references/lux-vs-ludus.md`.
2. Prefer LUX APIs for GOAD and consoles; Ludus API for range deploy/config/templates.
3. Do not invent OpenAPI paths — use list/describe tools or `docs/openapi.yaml`.
